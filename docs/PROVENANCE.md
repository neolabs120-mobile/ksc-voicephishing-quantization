# 코드 출처와 공개용 정리

이 저장소는 KSC 논문 작업 폴더 전체를 업로드한 것이 아닙니다. 최종 GGUF 양자화·평가에 필요한 코드를 골라 공개용 경로로 연결하고, 기존 결과에서 집계 수치만 추출했습니다. 원본 연구 폴더는 변경하지 않았습니다.

## 연구 코드

원 작업 폴더의 `decoder_distillation/scripts/`를 기준으로 다음 코드를 가져왔습니다.

| 공개 파일 | 역할 | 정리 범위 |
|---|---|---|
| `scripts/prepare_mobile_gguf.py` | F32 변환, 혼합 Q4/Q8 명령, 실제 저장 텐서 검사 | 도움말을 의존성 설치 전에 볼 수 있도록 `gguf` import만 지연 |
| `scripts/evaluate_mobile_gguf.py` | 토크나이저 일치 입력 준비, HF 기준값, 집계 | 바이트 동일 |
| `scripts/gguf_eval.cpp` | llama.cpp C API 추론, 첫 응답 위치 logit, 선택적 설명 생성 | 바이트 동일 |
| `scripts/common/` | CSV·JSONL 읽기, 해시, 지표, 학생 응답 계약 | 포함한 4개 파일은 바이트 동일 |
| `prompts/student_system_prompt.txt` | 학생 학습·평가의 고정 지시문 | 원본 체크포인트의 지시문과 바이트 동일 |

파일별 원천 상대경로와 원본·공개본 SHA-256은 [`SOURCE_MANIFEST.json`](../SOURCE_MANIFEST.json)에 있습니다. 이 코드는 연구 진행 중 작성한 실행 코드이며, llama.cpp나 랩실 ECoG의 원본 구현 자체라고 표시하지 않습니다.

## 공개용 연결 코드

`scripts/public_pipeline.py`, `CMakeLists.txt`, `tests/test_pipeline.py`는 공개용으로 정리하면서 구성했습니다. 기존 변환·추론·지표 함수를 사용하되, 개인 컴퓨터의 이전 실험 폴더가 없어도 경로를 인자로 지정할 수 있게 연결했습니다.

단일 블록 비교와 누적 비교는 기존 `run_gguf_block_sweep.py`, `run_gguf_cumulative.py`의 절차를 공개 실행 연결부로 옮겼습니다. Validation 순위는 Recall 내림차순, Macro-F1 내림차순, FPR 오름차순, 블록 번호 오름차순입니다. 누적 후보는 2~18블록의 17개입니다. 새 데이터에서 원래 블록 순위를 강제하지 않습니다.

누적 결과의 FPR 조건과 최대 Recall 후보를 파일에 기록하는 단계는 논문의 선정 기준을 명시한 공개용 추가 기능입니다. 원래 누적 실행기는 후보 표를 저장했으며 자동 최종 선정 기능이 있었다고 소급하여 주장하지 않습니다. 동률은 하나로 숨겨 고르지 않고 함께 남깁니다.

연구 당시 실행 서명과 기존 예측을 공개용 코드의 해시에 맞춰 고쳐 쓰지 않았습니다. `results/`의 수치는 기존 실험의 결과이고, 새 연결 코드로 전체 실험을 재수행했다고 표시하지 않습니다.

## 포함하지 않은 자료

Teacher 학습 원본, 응답 증류 학습기, 체크포인트, 통화 CSV, 개별 예측·응답·입력 토큰, 서버 접속 정보, 인증정보, RAG·앱 통합 코드는 이 공개본 범위에 포함하지 않습니다. 모델과 데이터의 사용·공유 조건은 각각의 원 출처에서 확인해야 합니다.
